# 🎓 Student Scoreboard Dashboard

A modern and interactive **Student Scoreboard Web Application** built using **React + Vite** to manage and analyze student performance in real-time.

---

## ✨ Overview

This project allows users to **add, track, and update student scores dynamically** while automatically calculating key performance metrics like total students, pass count, and average score.

Designed with a clean UI and responsive layout, this app demonstrates core **React concepts (state management, dynamic rendering, and component-based architecture)**.

---

## 🚀 Live Features

🔹 Add students with name & score
🔹 Real-time **Pass / Fail** status
🔹 Update scores instantly
🔹 Dynamic dashboard statistics:

* 👥 Total Students
* ✅ Passed Students
* 📊 Average Score

🔹 Clean & modern UI design
🔹 Fully responsive layout

---

## ⚡ How It Works

* User enters **Name** and **Score**
* App updates:

  * Total count
  * Passed count (score ≥ 40)
  * Average score
* Each student row allows:

  * Editing score
  * Saving updates
* UI updates instantly using React state
